# UniqueDevelopment Pawn Shop — versions

This repository only holds the **releases** of the UniqueDevelopment Pawn Shop script (no code).
The script checks the latest release on start and every hour, prints a warning in the server
console when a newer version is out, and shows it on the laptop ("Aurix Update").

- Latest version: see [Releases](../../releases)
- Each release tag is the version (`v1.0.0`), the release text is the changelog.

The script itself is available through UniqueDevelopment.
